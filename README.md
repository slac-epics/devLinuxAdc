# devLinuxAdc

[doi:10.11578/dc.20260908.2](doi.org/10.11578/dc.20260908.2)

EPICS device support for various ADCs under Linux.

Supported devices:
| Device | Driver | Description |
|---|---|---|
| Aquila AM-69 | am335x | Texas Instruments AM-69 SoC on Toradex Aquila SoM |

Any device using the am335x ADC driver just needs a DB file description.
